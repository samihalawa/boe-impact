# Evidencia histórica de ediciones anteriores

Los archivos de este directorio se preservan como registros de versiones anteriores, con sus fechas y alcances originales. Pueden contener nombres de funciones, rutas, pruebas de ejecución y descripciones técnicas que ya no forman parte de la edición actual 0.6.0 con conector remoto. No se deben interpretar como dependencias, funciones ni pruebas de aceptación actuales.

Las capturas oficiales conservan fuentes y fechas; una consulta histórica no prueba condiciones de hoy. Ningún registro archivado demuestra aprobación de esta edición en un directorio, consulta en vivo, compatibilidad universal ni resultados garantizados. Las instrucciones actuales y los criterios editoriales están en README.md, SKILL.md y DEVELOPMENT.md. Los documentos históricos no se reetiquetan ni se alteran para simular una nueva verificación.
